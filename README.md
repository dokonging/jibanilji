# 집안일지 (Android) · com.jibanilji.app

식품 소비기한과 집안일 루틴을 가족·친구와 함께 챙기는 앱.

## 화면
| 탭 | 내용 |
|---|---|
| 📅 모아보기 | 월 캘린더에 날짜별 아이콘 → 날짜 누르면 그날 챙길 목록 |
| 🧊 식품 | 소비기한 · 냉장/냉동/상온 · 수량 · 용량. 보관 방식 필터. 사진 찍으면 날짜/이름 자동 인식 |
| 🧹 집안일 | 추천 루틴 일괄 추가, N일/주/개월/년마다 또는 요일마다, 담당자, 완료 기록(누가·언제), 재고(선택) |
| 👥 함께 쓰기 | 초대 코드 공유 · 참여 · 집 이름 · 로그아웃 · 계정 삭제 |
| 🔑 로그인 | 구글 계정만 (처음이면 자동 가입) |

- 목록 행: 누르면 수정 / 길게 누르면 메뉴(완료 · 남은 수량·재고 수정 · 삭제) / 썸네일 누르면 크게
- 집안일 **완료**: 다음 할 날 갱신 + 재고 1개 차감 + 완료 기록
- 담당자를 지정하면 그 사람 폰에만 알림

## 유료 기능 구조 (`Premium.kt`)
- 같이 쓰기 + 식품·집안일 각 20개 초과 → 프리미엄 (가구 단위: 한 명 결제 시 모두 적용)
- 지금은 `ENABLED = false` → 전부 무료. 출시 때 Play 결제 연동 후 `true`
- `households/{hid}.premium` 값은 보안 규칙상 앱에서 못 바꾸고, 결제 확인 서버(Cloud Functions)만 변경

## 처음 한 번: Firebase 설정 (무료, 폰 브라우저로 가능)
로그인은 **구글 계정만** 사용해요.
1. https://console.firebase.google.com → 프로젝트 만들기 (`jibanilji`)
2. Android 앱 추가 → 패키지 이름 **`com.jibanilji.app`**
   → 같은 화면 "디버그 서명 인증서 SHA-1"에 아래 SHA-1 입력 → 앱 등록 (json은 아직 받지 않아도 됨)
3. Authentication → 로그인 방법 → **Google** 사용 설정 (지원 이메일 선택) → 저장
4. 프로젝트 설정(⚙️) → 내 앱 → **디지털 지문 추가**로 SHA-256도 등록
5. **3·4번을 마친 뒤** 프로젝트 설정에서 `google-services.json` 다운로드
   (Google 로그인을 켜기 전에 받은 파일이면 빌드가 실패해요)
6. Firestore Database → 만들기 → `asia-northeast3 (서울)` → 프로덕션 모드
7. Firestore 규칙 탭 → `firestore.rules` 내용 붙여넣고 게시

앱 서명키(`app/jibanilji.keystore`) 지문
```
SHA-1   78:AA:6C:9A:85:36:85:32:70:48:7D:60:A3:C8:D7:02:86:EB:74:1D
SHA-256 5B:5D:E8:A2:8C:4F:37:EE:D7:3F:02:6C:07:5E:24:FD:08:06:38:82:68:97:17:68:DD:A0:3F:85:0B:F7:C3:1C
```
(Play 스토어 출시 후에는 Play Console > 앱 서명의 SHA-1도 Firebase에 추가해야 구글 로그인이 돼요)
